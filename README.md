# Xyraniz

Repositorio personal para reunir proyectos, experimentos y material visual del perfil Xyraniz. Los archivos de este repositorio funcionan como presentación; los proyectos de código se mantienen en repositorios separados.

## Contenido

- `Synergy-Hub.PNG` contiene una captura relacionada con la interfaz de Synergy Hub.
- `digicamfx-original-2025-12-16T05-52-30.jpeg` conserva una imagen original del archivo visual.

Las imágenes se mantienen aquí como material de referencia. Para conocer el código o las instrucciones de cada proyecto, consulta los repositorios enlazados desde el perfil de GitHub.
